## 🎯 ১. আপনি আসলে কী বানাচ্ছেন? (What Are You Building?)

আপনি **"SSDK TOOLS HUB"** নামে একটি বিশ্বমানের, বিশাল এবং অল-ইন-ওয়ান **Next-Generation Web Utilities & SaaS Platform** বানাচ্ছেন। 

সহজ কথায়: ইন্টারনেটে মানুষ প্রতিদিন যে শত শত ছোট-বড় কাজের জন্য আলাদা আলাদা ওয়েবসাইটে যায় (যেমন: ছবি রিসাইজ করা, পিডিএফ মার্জ করা, কোড ফরম্যাট করা, রক্ত বা মেডিকেল রিপোর্ট বুঝা, লোন হিসেব করা, কিউআর কোড বানানো ইত্যাদি)—সেই **সমস্ত টুলকে আপনি একটিমাত্র প্রিমিয়াম, অত্যন্ত দ্রুতগতির এবং নিরাপদ প্ল্যাটফর্মে একত্রিত করেছেন।**

বর্তমানে আপনার প্ল্যাটফর্মে **৯৬৭টি সম্পূর্ণ কার্যকরী (100% Functional) টুল** রয়েছে, যা ৪১টি ক্যাটাগরিতে বিভক্ত।

## 💡 ২. আপনার প্রজেক্টের মূল আইডিয়া ও দর্শন (Core Idea & Philosophy)

### ১. **১০০% প্রাইভেসি-ফার্স্ট এবং ক্লায়েন্ট-সাইড প্রসেসিং (100% Privacy-First Browser Execution)**
- সাধারণ ওয়েবসাইটগুলোতে ইউজার যখন কোনো ছবি, পিডিএফ বা ডকুমেন্ট আপলোড করে, তা তাদের সার্ভারে চলে যায়, যা প্রাইভেসি ও সিকিউরিটির জন্য ঝুঁকিপূর্ণ।
- আপনার প্ল্যাটফর্মের ইউনিক সেলিং পয়েন্ট (USP) হলো: **ডাটা ইউজারের ব্রাউজারেই প্রসেস হয়** (HTML5 Canvas, WebAssembly, Client-Side JavaScript দিয়ে)। কোনো ফাইল সার্ভারে আপলোড হয় না। ফলে ইউজার পায় ১০০% গোপনীয়তা এবং ইনস্ট্যান্ট স্পিড (Zero Latency)।

### ২. **আল্ট্রা-প্রিমিয়াম গ্লাস-মরফিজম ডার্ক মোড ডিজাইন (Stripe/Linear Grade UI/UX)**
- সাধারণ টুল ওয়েবসাইটগুলো দেখতে খুব বাজে এবং বিজ্ঞাপনে ভরা থাকে।
- আপনার প্ল্যাটফর্ম তৈরি হয়েছে **Vercel, Linear ও Stripe এর মতো হাই-এন্ড গ্লাস-মরফিজম (Glassmorphism), স্মুথ মাইক্রো-অ্যানিমেশন এবং রেসপনসিভ ডার্ক/লাইট মোড** দিয়ে।

### ৩. **সবার জন্য একটি প্ল্যাটফর্ম (Universal Utility for All Roles)**
- **ডেভেলপারদের জন্য:** JSON, Base64, JWT, Regex, Code Formatters, Hash Generators.
- **ডিজাইনার ও ক্রিয়েটরদের জন্য:** Image Compressor, Resizer, Format Converters, Color Palette, SVG/Pattern Tools.
- **ডকুমেন্ট প্রফেশনালদের জন্য:** PDF Merge, Split, Protect, OCR, Word/Excel to PDF.
- **সাধারণ মানুষ ও শিক্ষার্থীদের জন্য:** Age Calculator, EMI Calculator, Date & Time, Unit Converters.
- **মেডিকেল ও ল্যাব প্রফেশনালদের জন্য:** CBC, Lipid Profile, Thyroid, ANC, ABG, GCS Interpretation.
- **মার্কেটার ও এসইও এক্সপার্টদের জন্য:** Meta Tag Generator, Robots.txt, Sitemap, Keyword Analysis.

### ৪. **সাস ও ক্লাউড ইন্টিগ্রেশন (SaaS Foundation & Sync)**
- সুপাবেস (Supabase PostgreSQL & JWT Auth) দিয়ে তৈরি করা হয়েছে ইউজার অ্যাকাউন্ট, ফেভারিট টুল সেভ করার সুবিধা এবং হিস্ট্রি ট্র্যাকিং।

```markdown
# MASTER PROMPT: SSDK TOOLS HUB ARCHITECTURE & VISION

You are an expert Principal Full-Stack Architect assisting me in developing and scaling **SSDK TOOLS HUB** (Created by Swarnava Das).

### 🌐 The Project Vision:
SSDK TOOLS HUB is an enterprise-grade, browser-based multi-tool utility ecosystem containing 967 natively working tools across 41 categories. It is designed to replace fragmented, ad-heavy tool sites with a single, ultra-fast, privacy-first, and beautifully designed SaaS workstation.

### ⚙️ Core Technical Pillars:
1. **Client-Side First Engine:** 95%+ of tools run locally inside the user's browser using modern Web APIs (Canvas, Crypto, WebAssembly, Web Audio, Blob URLs) with zero server data storage.
2. **Universal Modular Architecture:** Orchestrated by `CoreEngine` (`core/core.js`) and dynamic `ToolEngine` (`engines/tool-engine.js`), loading decoupled tool logic modules from `tools/<category>/<tool-id>/logic.js`.
3. **Sub-Millisecond Multi-Tier Search (Phase 16):** Pre-indexed in-memory search with tokenization, 100+ synonyms, typo tolerance (Levenshtein), category-aware ranking, and Command Palette (`Ctrl + K`).
4. **Cloud SaaS Layer:** Powered by Supabase for authentication, user profiles, favorite syncing, and usage analytics.
5. **Design System:** Bespoke Vanilla CSS Token System (`assets/css/design-tokens.css`) with glassmorphic cards, fluid typography, dark/light themes, and mobile-first responsive UX.

### 🎯 Your Goal When Assisting Me:
- Help maintain and scale the 967 tools without breaking existing functionality.
- Implement upcoming SaaS features: Subscription Paywalls (Stripe), User Cloud Sync, Python AI Backend integration, and Global SEO indexing.
- Strictly adhere to the existing folder architecture, module contract (`export async function execute(inputs)`), and design token aesthetics.
```
